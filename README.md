# 2FA 离线验证器

微软验证器等app原理就是保存码，然后后续使用码生成totp基于时间的验证码，由于基于微软账号这种广泛使用的app，所以有手机号，就能登录微软账号也就能登录author app，自然可以跨设备，不怕遗忘或者设备坏了等等。。。。。本项目纯离线，所以提供扫码时候弹出一个"2fa验证.勿分享或泄露.txt” ，的txt文本供保存，为2fa那个码的文本。。。也可以同时自己截图拍照或者记事本记录下码之类的。纯用于临时使用，因为github老是要求换 而且我登录了就能换也不需要再验证2fa，所以用后即抛。

## 使用方法

1. 通过 localhost 或 https 打开 2fa.html（摄像头扫码需安全上下文）。
2. 三种方式录入密钥：
   - ① 摄像头扫码（otpauth:// 或 Base32）
   - ② 上传二维码图片
   - ③ 粘贴/输入文本码（otpauth 链接或纯 Base32 密钥）
3. 录入成功后自动弹出下载 2fa验证.勿分享或泄露.txt（含 Secret / 位数 / 周期 / 算法 / otpauth 链接）。
4. 页面实时显示当前 TOTP 验证码及倒计时，可随时再次上传图片或粘贴文本重新生成。
5. 「下载备份文件」按钮可随时重新下载备份 txt。

## 文件

- 2fa.html：主页面，单文件、纯前端、无后端。
- jsQR.js：本地二维码解码库（离线，无 CDN 依赖）。

## 启动

    cd 2fa
    python3 -m http.server 8081
    # 浏览器打开 http://localhost:8081/2fa.html

## 说明

- TOTP 基于 RFC 6238，使用浏览器 Web Crypto（HMAC-SHA1/256/512）生成。
- 纯离线、不联网、不保存任何数据到服务器。
- 备份文件含密钥明文，请妥善保管，用后即抛。
